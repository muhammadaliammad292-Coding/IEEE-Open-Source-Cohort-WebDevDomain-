## 🌱 The Journey Begins

> **"This is the very beginning step of my journey to become a full stack MERN developer."**

By stripping away modern CSS frameworks and focusing purely on standard HTML5 architecture, this task establishes a rock-solid foundation in semantic web structure, document flow, and accessibility. Mastering standard document architecture—using tags like `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`—is the essential first step before moving into CSS styling, dynamic client-side interactivity with JavaScript & React, and server-side backend integration with Node.js, Express, and MongoDB.

## 🛠️ Page Structure & Architecture

The structure of `Task 2.html` adheres strictly to standard HTML5 semantics without reliance on presentational styling:

1. **Header & Navigation (`<header>`, `<nav>`):**

   * Main brand title `<h1>` for the **IEEE Student Branch**.

   * Announcement bar using standard `<marquee>` element.

   * Accessible button-based navigation bar links (`Home`, `About`, `Events`, `Why Join Us`, `Contact`).

2. **Hero Section (`<section>`):**

   * Prominent `<h2>` welcome heading and introduction.

   * High-resolution hero graphic (`hero.jpg`) with detailed accessibility attributes (`alt="IEEE Student Branch at LGU"`).

   * External button link directing users to the official [IEEE Student Branch Website](https://ieeesb.lgu.edu.pk/?utm_source=gemini) (opening in a new tab).

3. **About Section (`<section>`):**

   * Detailed overview of the IEEE Society's mission to foster technological innovation and provide student developers with mentorship and professional networking.

4. **Upcoming Events (`<section>`, `<article>`):**

   * Modular `<article>` blocks representing distinct events:

     * **Git & GitHub Essentials** (Version control, staging, committing, and GitHub workflows).

     * **Full-Stack Web Development Bootcamp** (Hands-on training transition from HTML markup to dynamic backend systems).

5. **Why Join Us (`<section>`):**

   * Unordered list (`<ul>`) mapping out core member perks: *Hands-on Experience*, *Global Network*, and *Resource Access*.

6. **Contact Intake (`<section>`, `<form>`):**

   * Native HTML5 interactive form with explicit `<label>` bindings, placeholder text, and strict `required` input attributes for **Name**, **Email**, and **Message**.

7. **Footer (`<footer>`):**

   * Formal copyright declarations and cohort build metadata.
